# 🤖 Turing Machine for String Manipulation

This project simulates a **Turing Machine** 🧠 that performs various string manipulation tasks using classical tape operations and state transitions. Designed for educational purposes, this program provides a hands-on demonstration of how Turing Machines work.

## ⚙️ Features Implemented

This simulator can perform the following operations:

|     Functionality        | Description                                                      |

| 1️⃣ String Concatenation | Combines two valid strings using a Turing Machine                 |
| 2️⃣ Palindrome Checker   | Checks whether a string is a palindrome using Turing transitions  |
| 3️⃣ Anagram Checker      | Checks if two strings are anagrams of each other                  |
| 4️⃣ String Reversal      | Reverses a string symbol by symbol on the tape                    |
| 5️⃣ Count Characters     | Counts the number of characters in a string                       |
| 6️⃣ Trim Spaces          | Trims leading spaces from a string                                |

---

## 🧾 How It Works

The program simulates a Turing Machine by:
- Using a `vector<char>` to represent the **tape**.
- Moving a **read/write head** across the tape.
- Replacing characters and changing states as per Turing logic.
- Visually displaying the tape and the current head position for each transition.

Each operation is carefully structured to follow the behavior of a deterministic Turing Machine.
